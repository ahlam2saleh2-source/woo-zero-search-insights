 Woo Zero Search Insights — CHANGELOG v1.2.0
 سجل التغييرات
════════════════════════════════════════════════════════════

Release date / تاريخ الإصدار: 2026-10-12

── NEW / جديد ──────────────────────────────────────────────

* Customer notifications — إشعارات الزبائن:
  Close the loop with the customer. From the logs page you can
  notify ONE customer (a Notify button next to every failed
  search of a registered user) or EVERYONE who searched a term
  (group by-product view), the moment a matching product exists.
  أغلق الحلقة مع الزبون: زر إشعار بجانب كل بحث فاشل لمستخدم
  مسجل، وزر جماعي في العرض المجمع لكل من بحث عن المصطلح.

* Two delivery channels — قناتا تسليم:
  In-store notification (a dismissible banner on the customer's
  next visit, with the product link) + HTML email (RTL aware).
  The admin picks the method per send. Guests are never
  notified — no account, no email — and the UI says so clearly.
  إشعار داخل المتجر (شريط قابل للإخفاء مع رابط المنتج) + بريد
  HTML؛ المدير يختار الطريقة؛ الضيوف لا يمكن إشعارهم وموضّح ذلك.

* Editable AR/EN templates — قوالب عربية/إنجليزية قابلة للتعديل:
  Commercial-ready default templates, per-recipient placeholder
  substitution ({customer_name} {term} {product_name}
  {product_url} {site_name}), per-user language on "auto"
  (falls back to the site language). Both languages editable
  from Settings.
  قوالب افتراضية تجارية جاهزة، تُعوض الحقول لكل مستلم، لغة
  تلقائية حسب لغة كل مستخدم، وقابلة للتعديل من الإعدادات.

* Searches by user / by product — البحث حسب المستخدم والمنتج:
  Filter the log by a specific user (or guests only) and see
  which of their searches failed; or open the grouped
  by-product view showing searches, registered audience
  (notifiable), guests and last search date per term.
  فلتر السجل بمستخدم محدد أو الضيوف فقط، وعرض مجمع حسب المنتج
  يظهر مرات البحث والمسجلين القابلين للإشعار والضيوف.

* Email health check — فحص صحة البريد:
  One-click diagnostics (wp_mail availability, default from
  address, detected SMTP plugins, last test result) plus a real
  test message that reports the exact failure reason captured
  from wp_mail_failed — notifications never go out blind.
  تشخيصات فورية لجاهزية البريد + رسالة تجريبية حقيقية تعرض سبب
  الفشل بدقة من خطاف wp_mail_failed.

* Customer notifications log — سجل إشعارات الزبائن:
  Every send is recorded: recipient, term, product, channel,
  language, status and the failure reason when any. Shown on
  the Health Check page and exportable via the privacy exporter.
  كل إرسال يُسجَّل: المستلم والمصطلح والمنتج والقناة واللغة
  والحالة وسبب الفشل — معروض في فحص الصحة وقابل للتصدير.

* Privacy integration extended — خصوصية موسعة:
  The WP personal-data eraser now also clears the in-store
  inbox and deletes notification rows for the user; the
  exporter includes the notification history.
  أداة المحو تمسح صندوق المتجر وصفوف الإشعارات، والمصدّر يشمل
  سجل الإشعارات.

── QUALITY / الجودة ───────────────────────────────────────

* 42 new E2E tests (notifications single/group, channels,
  template overrides, guest guard, mail health, privacy) —
  70/70 total suite passing, zero PHP warnings.
* New database table woo_zero_search_notifications (safe
  dbDelta upgrade) + inbox user-meta queue capped at 10.
* All new AJAX endpoints guarded by nonce + manage_woocommerce.

* 42 اختباراً جديداً (70/70 إجمالاً) بلا أي تحذيرات PHP، جدول
  إشعارات جديد بترقية آمنة، وحماية nonce + صلاحيات على كل نقطة.

── COMPATIBILITY / التوافق ─────────────────────────────────

WordPress 5.6+ (tested 7.1) · WooCommerce 5.0+ (tested 11.2)
PHP 7.4+ · HPOS + Cart/Checkout Blocks declared · Multisite
SQLite compatible (official integration)

── UPGRADE / الترقية ───────────────────────────────────────

Direct overwrite from 1.0.x / 1.1.0. The notifications table is
created automatically; nothing is deleted on deactivation.
ترقية مباشرة من 1.0.x أو 1.1.0 — جدول الإشعارات يُنشأ تلقائياً
ولا يُحذف شيء عند التعطيل.
