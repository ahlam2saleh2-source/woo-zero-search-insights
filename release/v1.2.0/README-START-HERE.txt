Welcome! This is the complete launch package for Woo Zero
Search Insights v1.2.0 — the release that closes the loop WITH
the customer: the store no longer just reports and maps search
gaps; it tells the very people who searched when the product
becomes available.

What's new in 1.2.0?
  • Customer notifications: per-row Notify button + group
    notify from the by-product grouped view
  • Two channels: in-store banner (next visit) or HTML email
    — admin chooses per send; guests are never notified
  • Ready-made commercial AR/EN templates, editable, with
    per-recipient placeholder substitution
  • Searches by user (their failed searches) and by product
    (audience per term: registered vs guests)
  • Email health check: diagnostics + real test message with
    the exact failure reason
  • Full notifications log + extended privacy (erase/export)

Package contents:
  1. woo-zero-search-insights-1.2.0.zip  (installable plugin)
  2. marketing/   (cover + ready Gumroad listing kit PDF)
  3. screenshots/ (9 official shots — one distinct theme each)
  4. docs/        (bilingual AR/EN guide PDF + changelog + GPL)

Quick start after activation:
  WP Admin → Zero Search → Logs:
  use the user filter to see any customer's failed searches,
  or "By product" for the grouped view, then press the bell
  button — pick the product, review the template, choose the
  channel(s), send.

Compatibility: WP 5.6+ (tested 7.1) · WC 5.0+ (tested 11.2)
PHP 7.4+ · Multisite · HPOS + Blocks · SQLite
