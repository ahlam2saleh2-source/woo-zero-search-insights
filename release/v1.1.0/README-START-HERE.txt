مرحباً بك! هذه حزمة إطلاق كاملة لإضافة Woo Zero Search Insights
الإصدار 1.1.0 — الإصدار الذي يحوّل الإضافة من أداة تقارير إلى
أداة نمو: الآن لا تكتشف فجوات البحث فقط بل تسدّدها.

ما الجديد في 1.1.0؟
  • الربط الذكي: مصطلح بلا نتائج ← منتج يظهر للزائر
  • تقرير بريدي يومي/أسبوعي يصل صندوق بريدك
  • إشعارات Telegram + عتبة إشعارات + زر اختبار لكل قناة
  • فلترة روبوتات الزحف + تطبيع عربي أعمق للمصطلحات
  • فلاتر بحث وتاريخ في السجلات + مقارنة الفترة السابقة
  • WP-CLI و REST للوكيلات + نسخ إعدادات JSON

Welcome! This is the complete launch package for Woo Zero
Search Insights v1.1.0 — the release that turns the plugin
from a reporting tool into a growth tool: it no longer just
finds search gaps, it closes them.

Package contents:
  1. woo-zero-search-insights-1.1.0.zip — installable plugin
     (Plugins → Add New → Upload Plugin; WooCommerce required)
  2. marketing/ — cover image + ready-made listing copy (PDF)
  3. screenshots/ — 7 official high-res screenshots
  4. docs/ — 18-page AR/EN user guide + changelog + GPLv2
  5. RELEASE-NOTES.md — quick publish summary

Quick start: upload & activate → monitor automatically →
click "Map 🔗" next to any zero term to close the gap.

Support / الدعم: through your purchase platform.
License / الترخيص: GPLv2 or later.
