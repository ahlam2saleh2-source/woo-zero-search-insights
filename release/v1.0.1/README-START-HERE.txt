مرحباً بك! هذه حزمة إطلاق كاملة لإضافة Woo Zero Search Insights —
إضافة وووكومرس التي تلتقط كل عمليات البحث التي لا تُرجع نتائج في
متجرك، وتحوّلها إلى فرص منتجات حقيقية.

محتويات الحزمة:
  1. woo-zero-search-insights-1.0.1.zip
     ← ملف الإضافة الجاهز للتثبيت مباشرة من
        لوحة تحكم ووردبريس: الإضافات ← أضف جديد ← رفع إضافة
        (يجب أن يكون WooCommerce مفعّلاً أولاً)

  2. marketing/
     ← marketing-cover.png : الغلاف الرئيسي لصفحة البيع (اقرأه أولاً
       في المعرض) + gumroad-listing-kit-AR-EN.pdf : كل النصوص
       الجاهزة للنسخ إلى صفحة Gumroad (العنوان، الوصف الكامل، FAQ،
       الوسوم، التسعير المقترح، ترتيب صور المعرض)

  3. screenshots/
     ← 6 لقطات حقيقية من متجر اختبار فعلي (ثيمات مختلفة، عربي/إنجليزي)
       ارفعها بترتيب الترقيم بعد صورة الغلاف

  4. docs/installation-user-guide-AR-EN.pdf
     ← دليل مستخدم مصوّر ثنائي اللغة (14 صفحة): التثبيت خطوة بخطوة،
       شرح كل إعداد، الإشعارات، الخصوصية، الأسئلة الشائعة، حل المشاكل
       ← أرفق هذا الملف كملف رقمي مع منتجك في Gumroad (Download)

  5. docs/CHANGELOG-1.0.1.txt  ← سجل التغييرات (عربي/إنجليزي)
  6. docs/LICENSE-GPLv2.txt    ← رخصة GNU GPLv2

خطوات سريعة للنشر على Gumroad:
  1) أنشئ منتجاً جديداً وارفع ملف الإضافة zip + دليل PDF كملفات التنزيل
  2) انسخ النصوص من gumroad-listing-kit-AR-EN.pdf إلى صفحة المنتج
  3) ارفع الغلاف ثم اللقطات الست بالترتيب المذكور في الحزمة التسويقية
  4) حدد السعر (اقتراحات في الحزمة التسويقية) وانشر

Welcome! This is the complete launch package for Woo Zero Search
Insights — the WooCommerce plugin that captures every zero-result
search in your store and turns it into real product opportunities.

Package contents:
  1. woo-zero-search-insights-1.0.1.zip
     ← Installable plugin. Upload via WP Admin → Plugins → Add New
        → Upload Plugin (WooCommerce must be active first)

  2. marketing/
     ← marketing-cover.png : main gallery cover + 
       gumroad-listing-kit-AR-EN.pdf : every ready-to-paste text for
       your Gumroad page (title, full description, FAQ, tags,
       pricing suggestions, gallery order)

  3. screenshots/
     ← 6 real captures from a live test store (multiple themes, AR/EN)
       Upload in numbered order right after the cover

  4. docs/installation-user-guide-AR-EN.pdf
     ← 16-page illustrated bilingual user guide: step-by-step install,
       every setting explained, webhooks, privacy, FAQ, troubleshooting
       ← Attach this as a digital download on your Gumroad product

  5. docs/CHANGELOG-1.0.1.txt  ← bilingual changelog
  6. docs/LICENSE-GPLv2.txt    ← GNU GPLv2 license

Quick publish checklist:
  1) Create a new Gumroad product, upload plugin zip + guide PDF
  2) Copy the listing texts from the marketing kit PDF
  3) Upload cover, then screenshots 1→6 in order
  4) Set your price (suggestions inside the marketing kit) and publish
